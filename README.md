# Movie-Review-Sentiment-Analysis 
This project uses Machine Learning to analyse movie reviews and classify them as positive or negative based on their text.

Tools & Technologies
- Python – Data processing and model development
- Google Colab – Writing and running the code
- Pandas & Scikit-learn – Data handling and machine learning
- IMDb Dataset – 50,000 labelled movie reviews

Models Used
- Logistic Regression with Unigrams
- Logistic Regression with Unigrams and Bigrams

Results
- Unigram Model Accuracy: 88.19%
- Unigram + Bigram Model Accuracy: 89.06%

Dataset
IMDb Large Movie Review Dataset (https://ai.stanford.edu/~amaas/data/sentiment/)

Objective
To demonstrate how machine learning can understand text and identify sentiment, with potential applications in customer feedback analysis and opinion mining.
